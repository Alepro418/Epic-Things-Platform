## 🎯 ¿Por Dónde Empezar?

### Si eres nuevo en el proyecto:

1. Lee el [README principal](../../README.md) para entender el proyecto.
2. Lee el [Código de Conducta](./codigo-conducta.md).
3. Configura tu [entorno local](./configuracion-local.md).
4. Revisa el [flujo de trabajo con Git](./flujo-trabajo-git.md).
5. Lee la [guía de contribución](./contribucion.md).

### Si quieres contribuir:

1. Busca un [issue abierto](https://github.com/Alepro418/epic-things-platform/issues).
2. Lee la [guía de contribución](./contribucion.md).
3. Sigue el [estilo de código](./estilo-codigo.md).
4. Envía tu Pull Request.

### Si eres creador de juegos:

1. Lee los [manuales para creadores](../manuales/creador/).
2. Consulta la [API de juegos](../arquitectura/api/games.yaml).
3. Únete al [Discord de la comunidad](https://discord.gg/epic-things).
