## 1. Resumen de Estrategia

Epic Things Platform utiliza un **modelo freemium con suscripciones** que beneficia tanto a jugadores como a creadores. La estrategia se basa en:

1. **Atraer** usuarios con contenido gratuito
2. **Convertir** usuarios a suscripciones con valor premium
3. **Retener** creadores con regalías justas
4. **Escalar** a través de la comunidad

## 4. Sistema de Regalías para Creadores

### 4.1. Estructura de Regalías

| Fuente de Ingreso | % para Creador | % para Plataforma |
| :--- | :--- | :--- |
| **Suscripción Gold (Creador)** | 70% | 30% |
| **Ventas de Juegos (Futuro)** | 70% | 30% |
| **Donaciones de Fans** | 80% | 20% |

### 4.2. Ejemplo de Ingresos para Creador

**Escenario:** Un creador con 100 suscriptores Gold ($15/mo)

- **Ingreso Total:** 100 × $15 = $1,500
- **Regalía del Creador (70%):** $1,050/mo
- **Comisión de la Plataforma (30%):** $450/mo

### 4.3. Tramos de Regalías (Futuro)

| Nivel de Ingresos | % para Creador |
| :--- | :--- |
| **Primeros $10,000/mo** | 70% |
| **$10,001 - $50,000/mo** | 75% |
| **$50,001+ /mo** | 80% |

## 6. Modelo de Costos

### 6.1. Costos Fijos Mensuales

| Concepto | Costo (USD) | Descripción |
| :--- | :--- | :--- |
| **Hosting (AWS)** | $300 | Servidores, base de datos, CDN |
| **Almacenamiento** | $100 | S3/MinIO para juegos y assets |
| **Stripe Fees** | $50 | 2.9% + $0.30 por transacción |
| **Dominio/SSL** | $10 | Renovación anual |
| **Herramientas** | $20 | GitHub, monitoreo, etc. |
| **Total** | **$480/mo** | |

### 6.2. Costos Variables

| Concepto | Costo | Descripción |
| :--- | :--- | :--- |
| **Ancho de Banda** | $0.10/GB | Descargas de juegos |
| **Almacenamiento** | $0.02/GB | Juegos y assets |
| **Stripe Fee** | 2.9% + $0.30 | Por transacción |

### 6.3. Punto de Equilibrio

- **MRR para cubrir costos:** $480
- **Usuarios Silver necesarios:** 96 ($5/mo)
- **Usuarios Gold necesarios:** 32 ($15/mo)
- **Mes de equilibrio:** Mes 3
